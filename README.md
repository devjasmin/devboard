# DevBoard

Ein Kanban-Board zur übersichtlichen Verwaltung von Aufgaben innerhalb verschiedener Liegenschaften.

## Funktionen

- Erstellen und Verwalten verschiedener Liegenschafts-Boards
- Aufgaben in den Status „Neu“, „In Bearbeitung“ und „Erledigt“ einteilen
- Aufgaben per Drag & Drop zwischen den Spalten verschieben
- Boardnamen bearbeiten
- Profilverwaltung
- Weitere Funktionen befinden sich aktuell in Entwicklung

## Technologien

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui
- React Router
